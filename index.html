Web Scraper — Book Catalogue Extraction

Python · Web Scraping

The problem

A bookseller wants competitor prices in a spreadsheet instead of opening 1,000 product pages by hand and copy-pasting titles, prices and ratings.

What I built

●Real output, not a mock-up: this exact table was produced by running the script below on 1 Nov 2026. First 6 of 20 books from page 1 shown; the full run covers all 1,000 books on the site.

The exact script behind the table

import urllib.request, re, html

url = "https://books.toscrape.com/"
req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
page = urllib.request.urlopen(req, timeout=25).read().decode("utf-8")

for art in re.findall(r'<article class="product_pod">(.*?)</article>', page, re.S)[:6]:
    title = re.search(r'<h3><a[^>]*title="([^"]+)"', art).group(1)
    price = re.search(r'price_color">([^<]+)', art).group(1)
    stars = re.search(r'star-rating (\w+)', art).group(1)
    print(html.unescape(title), "|", price, "|", stars, "stars")
